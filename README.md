# Bé Bin Đi Máy Bay ✈️

Ứng dụng tương tác cốt truyện & trò chơi kỹ năng sống dành cho trẻ em 4-8 tuổi trước chuyến bay đầu tiên.

## 🌟 Tính Năng Nổi Bật
- **13 Hoạt động tương tác trọn vẹn**: Trải nghiệm từ chuẩn bị tại nhà, sân bay, làm thủ tục, kiểm tra an ninh, lên máy bay, ứng xử văn minh trong khoang cho đến nhận lại hành lý.
- **Nhân vật Bé Bin & Gia đình**: Đồng bộ phong cách truyện tranh màu nước Comic Line-Art sắc nét.
- **Trắc nghiệm hình ảnh trực quan (Visual Choice Quiz)**: Trẻ dễ dàng tương tác, tư duy và nhận phản hồi trực quan mà không bị áp đặt đáp án văn bản.
- **Âm thanh Web Audio API sinh động**: Phản hồi tức thì khi thao tác thành công, đóng dấu vé, nhắc nhở an toàn.

## 🚀 Hướng Dẫn Cài Đặt & Chạy
1. Mở file `index.html` trực tiếp trên bất kỳ trình duyệt nào (Chrome, Edge, Safari, Firefox).
2. Hoặc bật tính năng **GitHub Pages** (Settings > Pages > Branch: `main`) để chơi trực tiếp trên web/máy tính bảng/bảng tương tác!
